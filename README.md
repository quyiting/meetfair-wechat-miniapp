# MeetFair · 聚点

一个用于朋友聚会的微信小程序 MVP：收集成员出发地，按通勤公平度推荐餐厅、电影院和其他娱乐场所。

## 本地预览

1. 使用微信开发者工具导入本目录；工具会识别 `project.config.json`。
2. 开通云开发，并部署下文列出的两个云函数。
3. 点击「发起一次聚会」开始创建聚会。

创建聚会时支持本地添加 2～8 位成员：每位成员可手动选出发位置，并独立设置交通方式和人均预算；“我”还可以调用微信原生定位。开发者工具中可使用模拟位置。

## 使用流程

1. **创建聚会**：设置聚会名称、活动类型（吃饭/看电影/喝咖啡/玩一玩）
2. **添加成员**：为每位成员设置出发位置、交通方式和预算
3. **搜索候选地点**：系统在成员折中区域附近自动搜索候选地点
4. **生成推荐**：系统会按公平度算法推荐最优地点
5. **查看结果**：在聚会详情页查看各地点的公平度评分和通勤时间
6. **投票决策**：对喜欢的地点进行投票

## 核心排序逻辑

聚会详情页可切换三种推荐目标：压低最远成员通勤时间（默认）、减少全员总通勤时间、缩小成员间的通勤时间差。每种目标都先比较对应的通勤指标，再用预算、类别匹配和评分等指标打破平局；切换只影响当前用户看到的排序。

配置高德地图后，排名靠前的 3 个候选地点会使用真实驾车、公交、步行或骑行路线耗时；其余候选地点以及路线接口失败的情况会回退到直线距离估算，界面会明确标注“估算”。

## 地点数据源与价格

地点搜索通过 `venueService` 云函数完成，地图 Key 和安全密钥不会进入小程序包。数据源按以下顺序选择：

1. **高德地图**（推荐）：云函数存在 `AMAP_KEY` 时优先使用，可返回人均消费与评分，并为排名靠前的地点计算真实路线。
2. **腾讯位置服务**：未配置 `AMAP_KEY` 时回退到 `QQ_MAP_KEY`。该数据源不返回人均价格与评分，当前版本的通勤时间使用估算值。

接高德的步骤：

1. 到 [高德开放平台](https://lbs.amap.com/) 创建应用，添加一个「Web 服务」类型的 Key。
2. 在云开发控制台为 `venueService` 配置环境变量 `AMAP_KEY`；若开启安全密钥，再配置 `AMAP_SK`。
3. 如果使用腾讯位置服务，则配置 `QQ_MAP_KEY`，以及可选的 `QQ_MAP_SK`。
4. 旧地图密钥曾经进入客户端源码时，应先在地图平台控制台作废，再配置新密钥。

## 聚会码与云开发

聚会详情页的**聚会码是 6 位**（字母数字，已剔除 0/O/1/I/L/J 等易混淆字符），可以直接口头念给朋友。

实现方式：聚会数据存在云数据库的 `rooms` 集合里，6 位码只是取件凭证。为此需要部署一次云函数：

1. 在微信开发者工具里确认已开通「云开发」，环境 ID 与 `miniprogram/app.js` 中的 `env` 一致。
2. 分别右键 `cloudfunctions/roomService` 和 `cloudfunctions/venueService` → **上传并部署：云端安装依赖**。
3. 首次创建聚会时云函数会自动创建 `rooms` 集合；若提示集合不存在，请在云开发控制台手动新建一个 `rooms` 集合。

`roomService` 负责创建、加入、投票、地点同步和删除聚会。聚会默认保留 30 天；创建者可以在详情页提前删除。未部署 `roomService` 时聚会码会回退为本地长码，但地点搜索仍需要 `venueService`。

## 当前限制

- 真实路线目前只计算预估排名靠前的 3 个地点，以控制地图 API 调用量；其他地点保留估算值。
- 腾讯位置服务模式暂未计算真实路线。
- 本地长码模式的数据不会跨设备持续同步，完整多人协作需要部署 `roomService`。
